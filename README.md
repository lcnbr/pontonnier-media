# Pontonnier media

Photographs, diagrams, PDFs and videos for the [Pontonnier website](https://lcnbr.github.io/pontonnier/).

The [Typst source repository](https://github.com/lcnbr/pontonnier) pins a commit
from this repository in `.media-revision`. Its CI publishes these files at the
website's existing `assets/` URLs. This repository is not synced into Typst.

See [media maintenance](docs/maintenance.typ) for updates and attribution.
The `source-before-media-split-2026-10-17` tag preserves the complete original
website repository history before its media was separated.
